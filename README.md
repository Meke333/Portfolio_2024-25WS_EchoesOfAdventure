# Information:
5th semester game project for winter semester 2024-2025 in the "Animation & Game" study course from the Darmstadt University of Applied Sciences "Hochschule Darmstadt" (h_da). This GitHub repository is there to display as part of my portfolio.

This game was also exhibited on the video game convention 'Gamescom' in the year 2025 as a booth within the 'Raw Talents' group that consists of student projects exhibitions.

# Summary
In this turn-based 2.5D singleplayer puzzle platformer game the player solves puzzles by repeating the same level with each character and their special abilities. These manifest as powerful echoes in the world, presenting additional challenges for the next character passing through if not used correctly. Join Tamo, Mukao and Cenali on their Adventure and help them face the consequences of their own actions!
